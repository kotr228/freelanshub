# FreelanceHub - Платформа для фрілансерів та замовників

Сучасна платформа на Node.js + React для ефективної взаємодії між фрілансерами та замовниками.

## 🚀 Технології

### Backend
- **Node.js** + **Express.js** - серверний фреймворк
- **MongoDB** + **Mongoose** - база даних
- **Socket.io** - чат в реальному часі
- **JWT** - автентифікація
- **bcrypt** - хешування паролів

### Frontend
- **React** + **Vite** - фронтенд фреймворк
- **React Router** - роутинг
- **Axios** - HTTP клієнт
- **TailwindCSS** - стилізація
- **Socket.io Client** - WebSocket з'єднання

## 📋 Функціонал

### ✅ Реалізовано

- **Автентифікація та авторизація**
  - Реєстрація користувачів (фрілансер/замовник)
  - Вхід/вихід з системи
  - JWT токени для безпеки

- **Управління проєктами**
  - Створення проєктів (для замовників)
  - Перегляд всіх проєктів з фільтрацією
  - Пошук проєктів за категорією та ключовими словами
  - Детальна інформація про проєкт

- **Система заявок (Bids)**
  - Подання заявок на проєкти (для фрілансерів)
  - Перегляд заявок (для замовників)
  - Прийняття/відхилення заявок

- **Рейтинги та відгуки**
  - Залишення відгуків після завершення проєкту
  - Автоматичне оновлення рейтингу користувача
  - Перегляд відгуків на профілі

- **Чат в реальному часі**
  - Socket.io для миттєвого обміну повідомленнями
  - Чат між замовником та фрілансером по проєкту
  - Індикатори typing

- **Профілі користувачів**
  - Профіль фрілансера (навички, портфоліо, ставка)
  - Профіль замовника (компанія, опис)
  - Редагування профілю

## 🛠️ Встановлення та запуск

### Передумови

- Node.js (v18 або вище)
- MongoDB (локально або MongoDB Atlas)
- npm або yarn

### 1. Клонування репозиторію

```bash
git clone <repository-url>
cd freelanshub
```

### 2. Налаштування Backend

```bash
cd backend
npm install
```

Створіть файл `.env` в папці `backend`:

```env
PORT=5000
NODE_ENV=development
MONGODB_URI=mongodb://localhost:27017/freelancehub
JWT_SECRET=your-super-secret-jwt-key
JWT_EXPIRE=7d
CLIENT_URL=http://localhost:3000
```

Запустіть MongoDB (якщо локально):

```bash
mongod
```

Запустіть backend сервер:

```bash
npm run dev
```

Сервер запуститься на `http://localhost:5000`

### 3. Налаштування Frontend

```bash
cd ../frontend
npm install
```

Створіть файл `.env` в папці `frontend`:

```env
VITE_API_URL=http://localhost:5000/api
```

Запустіть frontend:

```bash
npm run dev
```

Frontend запуститься на `http://localhost:3000`

## 🔑 API Endpoints

### Автентифікація
- `POST /api/auth/register` - Реєстрація
- `POST /api/auth/login` - Вхід
- `GET /api/auth/me` - Отримати поточного користувача

### Користувачі
- `GET /api/users/:id` - Профіль користувача
- `PUT /api/users/profile` - Оновити профіль
- `GET /api/users/freelancers` - Список фрілансерів

### Проєкти
- `GET /api/projects` - Всі проєкти
- `POST /api/projects` - Створити проєкт
- `GET /api/projects/:id` - Деталі проєкту
- `PUT /api/projects/:id` - Оновити проєкт
- `DELETE /api/projects/:id` - Видалити проєкт

### Заявки
- `POST /api/bids` - Подати заявку
- `GET /api/bids/project/:projectId` - Заявки проєкту
- `PUT /api/bids/:id/accept` - Прийняти заявку
- `PUT /api/bids/:id/reject` - Відхилити заявку

### Відгуки
- `POST /api/reviews` - Створити відгук
- `GET /api/reviews/user/:userId` - Відгуки користувача

### Повідомлення
- `GET /api/messages/:projectId` - Повідомлення проєкту
- `POST /api/messages` - Надіслати повідомлення

## 📝 Використання

### Для замовників:
1. Зареєструйтеся як замовник
2. Створіть проєкт з описом та бюджетом
3. Отримуйте заявки від фрілансерів
4. Оберіть найкращого виконавця
5. Спілкуйтеся через чат
6. Залиште відгук після завершення

### Для фрілансерів:
1. Зареєструйтеся як фрілансер
2. Налаштуйте профіль (навички, портфоліо)
3. Перегляньте доступні проєкти
4. Подайте заявку з вашою пропозицією
5. Виконайте роботу
6. Отримайте відгук від замовника
