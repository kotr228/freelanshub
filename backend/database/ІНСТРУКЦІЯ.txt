  ІНСТРУКЦІЯ: Як використати freelancehub.sql
═══════════════════════════════════════════════════════════

📋 ВАРІАНТ 1: PHPMyAdmin
────────────────────────────────────────────────────────────
1. Відкрийте PHPMyAdmin (http://localhost/phpmyadmin)
2. Натисніть вкладку "Імпорт" вгорі
3. Натисніть "Виберіть файл"
4. Оберіть файл "freelancehub.sql"
5. Натисніть "Вперед" внизу сторінки
6. Готово! ✅

────────────────────────────────────────────────────────────

📋 ВАРІАНТ 2: MySQL Workbench
────────────────────────────────────────────────────────────
1. Відкрийте MySQL Workbench
2. Меню: File → Open SQL Script
3. Оберіть файл "freelancehub.sql"
4. Натисніть іконку блискавки ⚡ (Execute)
5. Готово! ✅

────────────────────────────────────────────────────────────

📋 ВАРІАНТ 3: Командний рядок
────────────────────────────────────────────────────────────
Windows (PowerShell):
> cd "C:\xampp\mysql\bin"
> .\mysql.exe -u root -p < "шлях\до\freelancehub.sql"

Linux/Mac:
$ mysql -u root -p < /шлях/до/freelancehub.sql

Потім введіть пароль MySQL

────────────────────────────────────────────────────────────

✅ ПЕРЕВІРКА
────────────────────────────────────────────────────────────
У PHPMyAdmin або Workbench виконайте:

USE freelancehub;
SHOW TABLES;

Повинно з'явитися 7 таблиць:
✓ users
✓ projects
✓ bids
✓ reviews
✓ messages
✓ project_attachments
✓ message_attachments

🔧 НАЛАШТУВАННЯ BACKEND
────────────────────────────────────────────────────────────
Після створення БД, у файлі backend/.env додайте:

MONGODB_URI=mysql://root:password@localhost/freelancehub

Або використовуйте MongoDB Atlas як описано в MONGODB_SETUP.md
